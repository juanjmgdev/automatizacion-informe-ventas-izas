# Extracción automática de informes de ventas

**Tecnologías:** Python · pandas · openpyxl · SQL

Sistema desarrollado en **Python** que se conecta a la base de datos corporativa, ejecuta consultas **SQL** y genera informes de ventas en **Excel** de forma totalmente automatizada.

El proceso reemplaza la creación manual de reportes, reduciendo el tiempo operativo y garantizando la precisión de los datos.

**Resultado:** generación automática de informes en menos de 2 minutos en comparación con las horas que llevaba hacerlo manualmente.

> ⚠️ Por políticas de la empresa, el código fuente no puede hacerse público.  
> Este repositorio solo documenta el proyecto y su impacto.
